# DSA5208 Project 2 — Singapore Rainfall

Exploratory analysis of Singapore rainfall records from 2017–2024 using Apache Spark, and prediction of the probability that a station's accumulated rainfall over the next 30 minutes exceeds a given threshold.

## Completed experiments

- Cleaned records: 48,538,625; prediction origins with complete history and future windows: 47,048,853.
- Time split: 2017–2021 for training, 2022 for validation, 2023–2024 for testing.
- To limit local resource use, training origins are sampled uniformly at 10% using a fixed hash; validation and test keep the full sample, with no class-based sampling.
- Logistic regression, random forest and GBT are compared across 11 parameter combinations, together with a global-frequency baseline, a station-and-month frequency baseline, and an F0/F1/F2 feature ablation.
- Best model: GBT, 60 iterations, maximum depth 5.
- Main test (30-minute origins) mean Brier score: 0.014605; full five-minute test mean Brier score: 0.014598.
- The full five-minute test contains 13,025,429 prediction origins, each expanded into four thresholds: 0, 1, 5 and 10 mm.
- All 8 acceptance tests pass; the consistency check of 20 predictions after saving and reloading the final model passes.

## Reproduction

The reported run used WSL2 Ubuntu 24.04 on Windows, with Python 3.12, Java 11 and Spark 3.5.3; Spark `local[6]`, 4 GB driver memory and 16 shuffle partitions. Java is provided by `jdk4py`. Running through VS Code Remote - WSL is recommended.

```bash
git clone https://github.com/ZoroZhang000/dsa5208-project2.git
cd dsa5208-project2/code
python3 -m venv .venv-wsl
.venv-wsl/bin/python -m pip install -r requirements.lock.txt
.venv-wsl/bin/python -m pytest tests -q
.venv-wsl/bin/python rainfall.py download
SPARK_MASTER='local[6]' .venv-wsl/bin/python rainfall.py prepare
SPARK_MASTER='local[6]' .venv-wsl/bin/python run_experiments.py --from-stage train --training-fraction 0.1
```

The data source is [NEA Historical Rainfall across Singapore](https://data.gov.sg/collections/2279/view). Raw CSV files, cleaned and feature Parquet files, the virtual environment and debug output are not included in the repository; they are generated by running the download and processing commands. Predictions from the existing model also require the locally cleaned historical observations.

```bash
.venv-wsl/bin/python rainfall.py predict \
  --station S77 --time '2024-01-01T01:00:00+08:00' --threshold 5
```

The report's author field is left to be filled in. When compiling the LaTeX, keep the `figures/` directory alongside the source; the source has been checked for structure and figure references but has not yet been compiled.

## Data and interpretation boundaries

Missing observations are not filled with zero; the future window must contain six complete five-minute observations. A small number of early timestamps are aligned to within one second. Anomalous positive values are retained and audited. Full-year coverage and the number of valid days affect accumulated totals, so the report gives coverage, valid-day means and fixed-station comparisons together; no long-term climate trend can be asserted from these data.

Prediction assumes the observation at time t is already available; real-time publication delay was not verified. Threshold monotonicity was checked statistically but is not enforced; generalisation to thresholds not used in training and to independent new stations was not separately verified.
